**📰 PDF Text Extraction using PyMuPDF**
This project demonstrates how to extract text from PDF files using the powerful PyMuPDF (fitz) library in Python.

**🔧 Features**
- Extract text from each page of a PDF file
- Supports single and multi-page PDFs
- Simple and efficient code using PyMuPDF
- Cleanly structured for easy extension

**📦 Requirements**
- Python 3.x
- PyMuPDF
